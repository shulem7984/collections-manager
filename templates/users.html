Before deploying online

  • Set a long random SECRET_KEY and a unique administrator password.
  • Deploy behind HTTPS and use a managed database with automated encrypted backups.
  • Restrict access to authorized staff; collection records can contain sensitive personal information.
  • This starter has role separation, but a production deployment should add audit review, password reset/MFA, rate limiting, retention rules, and a tested restore process.
